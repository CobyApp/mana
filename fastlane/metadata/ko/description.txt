NOIZ — 노이즈가 살아있는 종이 같은 만화 리더.

ZIP, RAR, PDF로 가지고 있는 코믹과 만화를 한 라이브러리에서 읽으세요. 망가·글리치 톤의 디자인이 책을 펴는 매 순간을 작은 이벤트로 만들어 줍니다.

주요 기능
• ZIP / RAR / PDF 한 번에 — 포맷이 달라도 같은 라이브러리, 같은 리더.
• 싱글 / 듀얼 페이지, 좌→우 / 우→좌 진행 방향, 표지 단독 표시 지원.
• 폴더로 정리, 다중 선택으로 일괄 이동·삭제, 드래그 앤 드롭.
• 자동 재동기화 — 라이브러리를 Application Support에 보관하므로 앱을 다시 설치해도 작품이 그대로 돌아옵니다.
• 진행도 자동 저장 — 마지막으로 본 페이지에서 바로 이어 보고, 라이브러리의 표지에 진행 막대가 표시됩니다.
• 두 손가락 핀치 줌, 좌·우 탭으로 페이지 이동.
• 햅틱은 있고 소리는 없음 — 독서의 정적을 지킵니다.
• 망가·글리치 톤 UI — 하프톤 배경, 굵은 잉크 보더, 스피드라인.

요구 사항
• iOS / iPadOS 17.0 이상
• iPad Pro 권장

언어
앱 내 UI는 한국어, 日本語, English를 지원합니다. 설정에서 "시스템에 따름"을 선택하면 기기 언어를 자동으로 따라갑니다.

NOIZ는 광고가 없고 추적도 하지 않습니다. 가지고 있는 책을, 가지고 있는 기기에서 그대로 읽으세요.
