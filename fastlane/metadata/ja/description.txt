NOIZ — ノイズの効いた、紙のような漫画リーダー。

ZIP・RAR・PDF で持っている漫画やコミックを、ひとつのライブラリでまとめて楽しむアプリです。マンガ／グリッチ調のデザインが、ページをめくる瞬間を小さなイベントに変えます。

主な機能
• ZIP / RAR / PDF をそのまま — フォーマットを問わず同じライブラリ、同じリーダー。
• シングル／デュアルページ表示、左→右／右→左 の進行方向、表紙単独表示に対応。
• フォルダで整理、複数選択で一括移動・削除、ドラッグ＆ドロップ。
• 自動再同期 — ライブラリを Application Support に保存するため、再インストール後も作品が自動で戻ってきます。
• 続きから自動再開 — 前回読んだページにすぐ復帰。ライブラリの表紙に進捗バーが表示されます。
• 二本指ピンチでズーム、画面の左右タップでページ送り。
• ハプティクスあり、音は鳴らさない — 読書の静けさを大切に。
• マンガ／グリッチ調の UI — ハーフトーン背景、太字インクボーダー、スピードライン。

動作環境
• iOS / iPadOS 17.0 以上
• iPad Pro 推奨

言語
アプリ内 UI は 日本語 / 한국어 / English に対応。設定の「システムに従う」で端末の言語を自動追従します。

NOIZ は広告なし、トラッキングなし。お手持ちの本を、ご自身の端末でそのまま読んでください。
