よくある質問

対応フォーマット

ZIP（.zip / .cbz）、RAR（.rar / .cbr）、PDF（.pdf）。ZIP・RAR の場合はアーカイブ内の画像をページとして自動展開します。

ファイルの取り込み方

ライブラリ画面右上の「取り込み」ボタンか、ファイル App から NOIZ にドラッグ＆ドロップ。

再インストール後に作品が見当たらない

App を起動すると Application Support 内のファイルを自動再同期します。iCloud バックアップから復元した直後など、内部データの不整合がある場合は「設定 → ライブラリ初期化」で一度クリーンアップしてからインポートし直してください。

表紙ページを単独で表示したい

設定 → 「最初のページを単独表示」を ON に。デュアルページ表示で表紙を 1 ページとして見せ、その後を 2 ページずつ並べます。

アプリの言語を変えたい

設定 → アプリ言語で「システム / 日本語 / 한국어 / English」のいずれかを選択。「システム」を選ぶと端末の言語に追従します。

価格と広告について

本アプリは完全無料で、広告および計測 SDK は一切含まれていません。

자주 묻는 질문

지원 포맷

ZIP(.zip / .cbz), RAR(.rar / .cbr), PDF(.pdf). ZIP·RAR 의 경우 아카이브 내부 이미지를 페이지로 자동 전개합니다.

파일 가져오는 법

라이브러리 화면 우측 상단의 "가져오기" 버튼을 누르거나, 파일 앱에서 NOIZ로 드래그 앤 드롭.

재설치 후 작품이 안 보입니다

앱을 실행하면 Application Support 안의 파일을 자동 재동기화합니다. iCloud 백업 직후 등 내부 데이터 불일치가 있을 경우 "설정 → 라이브러리 초기화"로 한 번 정리한 뒤 다시 가져오기를 해보세요.

표지를 단독으로 보고 싶어요

설정 → "첫 페이지 단독"을 켜기. 두 페이지 모드에서 표지를 1페이지로, 이후를 2페이지씩 펼쳐 보여줍니다.

언어를 바꾸고 싶어요

설정 → 앱 언어에서 "시스템 / 한국어 / 日本語 / English" 중 하나를 선택. "시스템"을 고르면 기기 언어를 자동 추종합니다.

가격과 광고

완전 무료이며, 광고나 추적 SDK는 일절 포함하지 않습니다.

FAQ

Supported formats

ZIP (.zip / .cbz), RAR (.rar / .cbr), PDF (.pdf). For ZIP and RAR, images inside the archive are unpacked as pages automatically.

Importing files

Use the "Import" button in the top-right of the library, or drag & drop from the Files app onto NOIZ.

Comics disappeared after a reinstall

The app reconciles Application Support files on launch. If state is inconsistent right after an iCloud restore, run Settings → Reset Library once and re-import the files.

Show the cover as a single page

Enable Settings → First Page Solo. In dual-page mode the cover stays solo and every subsequent page pairs in twos.

Change the app language

Settings → App Language lets you pick System / 日本語 / 한국어 / English. "System" follows the device locale.

Pricing and ads

The app is free and contains no ads, no tracking SDKs.
